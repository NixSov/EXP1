# MC Вместе — голосовой чат и игра по сети для Minecraft PE

Приложение для Android, которое делает две вещи сразу:

1. **Голосовой чат.** Голос слышно всем в комнате на любом расстоянии. Микрофон включается и
   выключается **плавающей кнопкой поверх игры**.
2. **Подключение к миру друга без Xbox, Realms и выделенного сервера.** Мир, открытый на телефоне
   хоста, появляется у гостей во вкладке «Друзья → LAN-игры», даже если вы в разных городах.

```
Телефон хоста                      Сервер «MC Вместе»                 Телефон гостя
Minecraft (мир, порт 19132)  <->   комнаты, голос,         <->   приложение притворяется
приложение «MC Вместе» (хост)      пересылка пакетов              LAN-миром -> Minecraft
```

## 1. Сервер (один раз)

Нужен любой хостинг с Node.js 18+ и WebSocket. Проще всего бесплатный **Render**:

1. Зарегистрируйся на https://render.com через GitHub.
2. **New → Blueprint**, выбери репозиторий `NixSov/EXP1`, ветку `claude/minecraft-pe-mod-nlpmnh`.
   Render найдёт `render.yaml` и создаст сервис `mc-together`.
3. После сборки появится адрес вида `mc-together-xxxx.onrender.com`. Его вводят в приложении.

На бесплатном тарифе Render сервис засыпает через 15 минут без подключений. Первое подключение
после сна занимает до минуты, после этого всё работает как обычно.

Свой ПК или VPS тоже подойдёт: `cd Together/server && npm ci && npm start`, порт задаётся
переменной `PORT` (по умолчанию 8080). В приложении тогда вводится `IP:8080`.

## 2. Приложение

Установи `dist/MCVmeste.apk` и разреши установку из неизвестных источников.

**Хост** (мир на его телефоне):
1. В Minecraft открой мир. В настройках мира включи **«Многопользовательская игра»** и
   **«Видимый для игроков LAN»**.
2. В «MC Вместе» введи адрес сервера, придумай код комнаты, выбери **Хост** и нажми «Подключиться».
3. В приложении должна появиться строка «Мир: …».

**Гость:**
1. Включи Wi-Fi: Minecraft ищет LAN-игры только через Wi-Fi. Подойдёт любая сеть.
2. Введи тот же сервер и код комнаты, выбери **Гость** и нажми «Подключиться».
3. Minecraft → Играть → **Друзья** → **LAN-игры** → мир хоста.

**Кнопка микрофона поверх игры:** нажатие включает или выключает микрофон, перетаскивание
перемещает кнопку, долгое нажатие открывает приложение. Зелёная — микрофон включён,
красная — выключен, серая — нет связи. Подсветка вокруг кнопки значит, что кто-то говорит,
цифра — сколько людей в комнате. Микрофон можно переключать и из уведомления.

## Ограничения

- Пакеты игры идут через сервер, поэтому пинг выше, чем в настоящей локальной сети.
- Голос: μ-law 16 кГц, около 128 кбит/с на каждого говорящего. Тишина не передаётся.
- Играй в наушниках, иначе микрофон ловит звуки игры.
- Может ли хост принимать игроков без входа в Xbox, зависит от версии Minecraft. Если гость не
  может зайти, попробуйте, чтобы оба были без входа в аккаунт или оба с входом.
- Обычно в комнате один хост и до 15 гостей.

## Сборка

```
cd Together/server && npm ci && npm test        # проверка сервера
cd Together/android && gradle assembleRelease   # нужен Android SDK (sdk.dir в local.properties)
```

Ключ подписи в репозитории не хранится. Положи `keystore/mctogether.jks` и `keystore.properties`
(storeFile, storePassword, keyAlias, keyPassword) в `Together/android/`, иначе APK подпишется
отладочным ключом. Обновление ставится поверх старой версии, только если ключ тот же.
