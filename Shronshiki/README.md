# Shronshiki — голосовые комнаты

Голосовой чат с комнатами до 4 человек. Аккаунты — как в Discord, быстрый вход по коду — как в Телемосте.
Звук идёт напрямую между телефонами (WebRTC mesh), сервер нужен только для аккаунтов,
списка комнат и обмена служебными сообщениями при подключении.

- **Flutter** — один код для Android (сейчас) и Windows (позже).
- **flutter_webrtc** — P2P-звук, каждый участник соединён с каждым.
- **Supabase (бесплатный тариф)** — Auth (почта/пароль + анонимный вход для гостей),
  Postgres (профили и комнаты), Realtime (сигналинг и список участников).
- **STUN** Google, **TURN** — бесплатный Open Relay от metered.ca (по желанию).

## Настройка (один раз)

### 1. Проект Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (тариф Free).
2. **SQL Editor → New query** — вставьте целиком файл
   [`supabase/migrations/20261026000000_init.sql`](supabase/migrations/20261026000000_init.sql) и нажмите **Run**.
   Файл можно запускать повторно — он ничего не сломает.
3. **Authentication → Sign In / Providers**:
   - включите **Allow anonymous sign-ins** (нужно для гостей);
   - в разделе **Email** выключите **Confirm email** — встроенная почта Supabase на бесплатном
     тарифе отправляет всего несколько писем в час. Если оставить подтверждение включённым,
     после регистрации нужно перейти по ссылке из письма.
4. **Project Settings → API** (или **API Keys**): скопируйте **Project URL** и **anon public**
   (или **publishable**) ключ.

### 2. TURN-сервер (если участники не слышат друг друга)

Через мобильный интернет прямое соединение иногда не проходит — тогда звук пускается через TURN.

1. Зарегистрируйтесь на [metered.ca](https://www.metered.ca/tools/openrelay/) (бесплатный план, карта не нужна).
2. Создайте TURN-приложение и откройте его учётные данные: список адресов
   (`turn:...:80`, `turn:...:443?transport=tcp`, …), **username** и **credential**.

### 3. Файл настроек

Скопируйте `config/app_config.example.json` в `config/app_config.json` и впишите свои данные.
Этот файл в `.gitignore` и в репозиторий не попадает.

```json
{
  "SUPABASE_URL": "https://xxxx.supabase.co",
  "SUPABASE_ANON_KEY": "eyJ...",
  "TURN_URLS": "turn:global.relay.metered.ca:80,turn:global.relay.metered.ca:443?transport=tcp",
  "TURN_USERNAME": "...",
  "TURN_CREDENTIAL": "..."
}
```

Если APK собран без этого файла, приложение при первом запуске само попросит ввести адрес
и ключ (их можно поменять потом в **Настройки → Сервер**).

## Сборка APK

Нужны [Flutter](https://docs.flutter.dev/get-started/install) 3.38+ и Android SDK.

```bash
cd Shronshiki
./tool/build_apk.sh        # результат: dist/Shronshiki.apk и dist/Shronshiki-armv7.apk
```

`Shronshiki.apk` (arm64) подходит почти для всех телефонов последних лет,
`Shronshiki-armv7.apk` — для старых 32-битных.

Без скрипта: `flutter build apk --release --dart-define-from-file=config/app_config.json`.

Готовая сборка без встроенных ключей лежит в [`../dist/Shronshiki.apk`](../dist/Shronshiki.apk)
(и [`../dist/Shronshiki-armv7.apk`](../dist/Shronshiki-armv7.apk) для старых телефонов):
установите её, при первом запуске введите адрес и ключ Supabase.

## Как проверить

1. **Вход:** вкладка «Регистрация» → имя, почта, пароль. Затем «Выйти» в настройках и «Вход» снова.
2. **Комнаты:** «Создать комнату» → появится код из 6 символов. Комната видна в «Мои комнаты»,
   её можно переименовать, удалить, скопировать приглашение.
3. **Гость:** на втором телефоне вкладка «Гость» → имя и код. Ссылка `shronshiki://join/КОД`
   открывает приложение сразу с этим кодом (некоторые мессенджеры такие ссылки не подсвечивают —
   тогда достаточно кода).
4. **Звонок:** оба телефона в комнате слышат друг друга; у говорящего зелёная рамка;
   кнопки «Микрофон», «Динамик/Наушники», «Выйти». Проверьте и через мобильный интернет.
5. **Лимит:** пятый участник видит «Комната заполнена».
6. **Фон:** сверните приложение или выключите экран — звонок продолжается, в шторке уведомление
   с кнопкой «Отключиться». Если на телефоне агрессивная экономия батареи (Xiaomi, Huawei, …),
   нажмите **Настройки → Не ограничивать в фоне**.
7. **Шумоподавление:** переключатель в настройках, действует со следующего входа в комнату.

## Как это устроено

```
lib/
  main.dart                    выбор экрана: настройка сервера → вход → главная
  app_state.dart               Supabase, настройки, ссылки-приглашения
  config.dart                  URL/ключ Supabase, STUN/TURN
  services/
    call_controller.dart       WebRTC mesh + сигналинг через Supabase Realtime
    background_call.dart       foreground service на Android
    rooms.dart                 комнаты (таблица rooms, функции create_room / find_room)
    settings.dart              шумоподавление, громкая связь
  screens/                     экраны: вход, главная, комната, настройки
supabase/migrations/           SQL-схема и политики RLS
```

- Канал Realtime `room:<id комнаты>` приватный: подключиться могут только вошедшие
  пользователи (в т.ч. гости) и только к существующей комнате.
- **Presence** — кто в комнате, имя, выключен ли микрофон. Перед входом приложение смотрит, сколько
  людей в комнате; если уже 4 — «Комната заполнена». Если двое вошли одновременно на последнее
  место, остаётся тот, кто вошёл раньше.
- **Broadcast** — offer/answer/ICE-кандидаты. Offer отправляет участник с меньшим идентификатором,
  поэтому встречных предложений не бывает. При обрыве соединение перезапускается (ICE restart).
- Индикатор голоса — уровень звука из статистики WebRTC (`audioLevel`). Свою рамку вы увидите,
  только когда в комнате есть кто-то ещё.
- Создавать комнаты могут только зарегистрированные пользователи (проверяется политикой RLS).

## Доступ из России

- Supabase, metered.ca и Flutter работают без оплаты, карта не нужна.
- Если у кого-то из участников не открывается `*.supabase.co` (провайдеры иногда блокируют
  отдельные адреса облаков), приложение покажет ошибку подключения — поможет другой интернет
  или VPN. Сам звук идёт напрямую между телефонами.
- STUN-серверы Google иногда работают нестабильно — тогда соединение пойдёт через TURN.

## Планы

- RNNoise для более сильного шумоподавления.
- Версия для Windows (`flutter build windows`; фоновый сервис и переключатель динамика там не нужны).
