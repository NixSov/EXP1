- TURN-серверы теперь приходят с сервера: вписывать их на каждом телефоне не нужно, и их может быть несколько.
- «Проверить прямое соединение» проверяет каждый TURN отдельно.
- Демонстрация во весь экран занимает весь экран; на телефоне её можно повернуть боком.
- Приложение реже обращается к серверу, чтобы не исчерпать лимиты посредника.
