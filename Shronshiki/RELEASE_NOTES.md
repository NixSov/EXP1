Улучшено обновление Windows: установщик заменяет копию приложения, из которой запущено обновление, включая нестандартную папку. Существующий ярлык рабочего стола обновляется независимо от прежнего выбора задачи установки; ярлык меню «Пуск» пересоздаётся с правильной рабочей папкой.

При обновлении учитывается блокировка app.so с кодом Flutter. Отключён дополнительный перезапуск через Restart Manager: новую версию запускает установщик. Ход установки и ошибки теперь видны; сохраняется журнал установки для диагностики.

Сохранены изменения сборки 127: произвольные коды комнат, фотографии в обоих чатах, компактный звонок на компьютере, закрепление трансляции и очистка чата пустой комнаты.
